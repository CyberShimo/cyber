Vault

Anything you keep is stored in this browser only. Nothing is uploaded. Paste a link you were given privately and it saves the same as any other — it just never becomes searchable by anyone else.

Settings
Your browser refuses to read most archive APIs directly — a security rule called CORS. A relay is a middleman server that fetches the page for you and hands it back with permission attached. The public ones need no setup but are shared with strangers, so they're slow and get rate-limited. Running your own fixes that.
Free from Google Cloud Console — make a project, enable "YouTube Data API v3", create an API key, then restrict it to your own domain under HTTP referrers. This is what makes channel-by-name search and full upload listings reliable. 10,000 units a day free; a name search costs 100, a channel listing about 3.
Comma-separated. Volunteer-run YouTube mirrors with an open API, used when you have no key. They go down constantly, so each is tried in turn until one answers. Add more if they all fail.
